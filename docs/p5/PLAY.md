# Sunset Viaduct 游戏指南

从桌面构建归档启动 OFE，或在装好原生扩展后用 Godot 4.7.2 打开 runtime 项目并按 F5。主菜单可用鼠标，也可用方向键或 Tab 选择、Enter 确认、Esc 返回。[源码构建步骤](../development/GETTING_STARTED.md)

Local duel 是双人对战，Team battle 将 P1/P2 与 P3/P4 分为两队，Free-for-all 为四人各自作战。每个席位可重复选择同一名角色。选择 Continue 查看阵容，按 Fight 开局。最后存活队伍获胜，同时全灭为平局。Esc 暂停，可以继续、查看操作、重赛或返回主菜单。

|动作|P1|P2|P3|P4 小键盘|手柄|
|---|---|---|---|---|---|
|移动|A / D|← / →|Z / C|4 / 6|十字键左右|
|跳跃 / 换线|W / S|↑ / ↓|X / V|8 / 2|十字键上下|
|普通攻击 / 防御|J 或 O / K|F / G|B / N|1 / 3|A / B|
|冲刺|L|H|M|5|LB|
|特殊技 / 超必杀|U / I|R / T|逗号 / 句号|7 / 9|X / Y|

Amber 的 tap 命中后可以取消进入 updraft 升龙，再接 sunbreak。Indigo 的 flick 距离更长、收招更快，可以直接接 needle 飞行道具或 nightfall 双段超必杀。双方开场能量 40，发动超必杀消耗 24。菜单 Settings 可分别调整音乐和音效，音量保存在本机。

## 训练场

以 P1 操作选定角色。屏幕上方显示两人的原生状态、当前招式、坐标、启动/有效/恢复帧、受击/格挡硬直、连击数和最近一次命中的伤害。底部工具栏可用鼠标点击。

|按键|作用|
|---|---|
|F1|轮换假人站立、防御、受击后防御|
|F2|显示或隐藏攻击框、受击框和推挤框|
|F3|切换有限或无限生命|
|F4|重置位置与整局状态|
|F5|切换四分之一速和常速|
|F6 / F7|冻结或继续 / 单帧推进|
|F8|从初始位置开始记录，再按一次停止|
|F9|从相同初始条件回放，结束时停在最后一帧|
|F10 / F11|保存到本机 / 读取并播放已保存的录像|

每次记录最多 36,000 个战斗帧，录制完成后按 F10 可保存在本机，退出训练后仍可再次打开。开始新记录会替换内存中的输入。再次按 F10 才会替换磁盘文件。[录像校验与文件位置](../p6/REPLAY.md)训练帧数以固定 60 Hz 战斗时钟计量。

## 内容与素材

内置两份 OFC 各包含三招、取消窗口、属性与碰撞框，图集沿用 P4 的原创图像。Sunset Viaduct 是工程原创的双线高架舞台。循环配乐由本项目合成，包含低音、旋律及节奏声部，命中和格挡分别触发音效。循环音频和内置示范角色数据依 CC0-1.0 提供。[素材来源](../p4/RUNTIME.md)

启动可用 `-- --p1-dir="/absolute/path"` 等选项为指定席位载入外部 OFC 目录；四人模式最多支持 `--p4-dir`。选人界面会标明被替换的席位。支持的技能键由该角色实际配置的招式数决定。
