# P5 任务书 V1.0 · 离线示范游戏

本阶段依据[项目总任务书 V1.0 第八章、P5 和第十四章](../governance/PROJECT_CHARTER_V1.0.md)。公共运行时契约见 [ADR-008](../architecture/ADR-008.md)。

|交付项|运行验收|
|---|---|
|默认游戏入口|从主菜单选择本地 1V1、2V2、四人自由混战或训练。各席位选择内置角色，VS 显示实际阵容，战斗 HUD 展示对应原生状态。|
|战斗流程|双方可移动、切线、攻击、格挡和冲刺。暂停冻结原生帧；继续后按原帧序推进。依据存活队伍显示胜负或平局，并可重赛或返回菜单。|
|角色与舞台|至少两份独立 OFC。平衡型角色有升龙类技能，另一名角色有不同射程、节奏、取消路线、特殊技及超必杀。在一张原创双线舞台中实际运行。|
|音频与设置|游戏中有可听的背景音乐及事件音效，设置界面可调整音频；通过真实输出或运行时播放状态验证。|
|训练|按总纲 8.4 完整展示帧数据、状态、招式、连击、伤害、坐标和三类框。验证站立、防御、受击、无限生命、复位、慢速、单帧和本次训练输入记录与回放。|
|运行证据|保留旧场景回归，验证从编辑器与导出程序进入 P5。记录真实窗口平均 FPS、慢帧、采样窗口和物理步耗时。记录平台、测试入口及未验证项，交负责人验收。|

角色动作与技能参数由 OFC 驱动；规则、输入校验、战斗步进与状态观测通过公开引擎 API 完成。呈现层负责选择、菜单、局内控制、训练输入记录、回放调度及舞台音画。P6 的可持久化确定性回放与恢复按总纲另行实施。
