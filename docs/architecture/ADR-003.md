# ADR-003 · Godot 绑定与首次导入
目标引擎锁定官方 Godot 4.7.2-stable（ed1daf0bf），godot-cpp 锁定 10.0.0-stable（507ed9d840c01a3c5b2a39af8bb4000bfac30bf5），生成面向 4.7 API 的绑定。CMake 与 Cargo 统一产出平台共享库；每个安装目录使用对应目标架构。技术 PoC 放在 integrations/godot/runtime，后续示范游戏有独立入口。

开发与独立 QA 都观察到 ARM64 下，首次 headless 编辑器扫描动态发现扩展后在退出时收到信号 11。切换到 4.7 绑定仍复现。预登记引擎的项目扩展列表，使 Godot 在进程启动阶段加载同一个共享库。安装后须真实运行编辑器导入、场景和错误路径，保留退出码。首次打开项目的支持入口为构建、安装后再导入；删除项目的 .godot 缓存后须重新执行安装步骤。此决议只涉及加载时机，ABI 与数据格式沿用 ADR-001/002。上游崩溃的底层原因仍待定位。
