# ADR-011 · P8 候选发行与默认键位

依据项目总纲第十章 P8 和项目负责人的键位要求，本阶段使用同一源码提交构建 Windows x64、Linux x64、macOS ARM64、macOS x64 的 Release 版游戏和模拟器，另提供通用作者包。各桌面任务验证解包后的程序，汇总任务在四端完成后核查清单并生成 SHA-256。版本取自仓库根目录 VERSION。验收对象是对应构建记录中的候选文件，正式公开需项目负责人签收并授权。

一号位用 WASD 移动、跳跃与换线，J/K/L 对应普攻、防御和冲刺，U/I 对应特殊技和超必杀。O 作为普攻的第二个按键，使用既有动作位。二号位使用方向键与 F/G/H/R/T，两个席位可以共用同一键盘。手柄布局和录像中的动作编号继续兼容 P6。游戏内操作页与发布说明提供相同映射。
