# ADR-001 · P0 接口冻结
Tech Lead 决议。Godot 4.7.2 stable → godot-cpp → C ABI v1 → Rust 1.100.0。只有 combat-core 推进权威状态。P0 单实体样例只验证输入到坐标的数据链。引擎坐标 i32，X 向右、Z 向后、H 向上。前线 0 后线 1000。每 tick 为 1/60 秒，水平输入 -1/0/+1，每帧移动一个逻辑单位。Godot 展示投影使用可配置纵深系数。

Rust crate 名 ofe-combat-core。Battle::new()，Battle::submit(frame: u64, axis: i32) -> Result<(), Error>，Battle::step() -> Result<(), Error>，Battle::snapshot() -> Snapshot。Snapshot 含公开 frame: u64, entity_id: u32, x/z/h: i32。帧从 0 开始，提交下一帧，缺省中立，拒绝重复输入、错误帧和非法方向。实体 ID 从 1 开始。步进失败保持原状态。快照须包含下一帧待处理输入。内部附加接口由核心维护者记录。

C ABI 名称 ofe_v1_create(uint64_t *out), ofe_v1_destroy(uint64_t handle), ofe_v1_submit(uint64_t handle,uint64_t frame,int32_t axis), ofe_v1_step(uint64_t handle), ofe_v1_read(uint64_t handle,ofe_state_v1 *out)。均返回 int32_t，成功 0。状态布局依次为 uint32_t size,version; uint64_t frame; uint32_t entity_id; int32_t x,z,h。调用方初始化 size = sizeof(ofe_state_v1)，version = 1。调用方拥有输出，Rust 拥有实例，句柄为进程内唯一非零 token，不重用。空指针、旧句柄、重复释放均返回错误。调用期间指针须有效且正确对齐。串行化访问，宿主保证同实例调用顺序。C++ 对象使用 RAII。
