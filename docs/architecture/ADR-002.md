# ADR-002 · P0 交换格式与 ABI v1 契约冻结

本决议补充 ADR-001。技术负责人确认后，变更公共契约须附迁移或版本决议。

## Godot 桥接

五个函数的原型及字段顺序见 ADR-001。读取者填写 `size = sizeof(ofe_state_v1)`（当前 32 字节）、`version = 1`。支持更大的调用方缓冲区，此时只写 v1 前缀。size 太小或 version 不匹配返回不兼容错误。创建和读取失败时保留输出；步进或输入失败时保留实例状态。create 成功只写一个句柄。read 返回当前已提交模拟帧的展示状态，待提交输入仅属于 Rust 权威快照。

| int32_t | 含义 |
|---|---|
| 0 | 成功 |
| 1 | 参数无效，包括空指针或非法水平轴 |
| 2 | 无效或已释放句柄 |
| 3 | 输出结构大小或版本不兼容 |
| 4 | 非下一帧，或该帧已有待处理输入 |
| 5 | 数值溢出、标识符耗尽或资源容量限制 |
| 6 | 内部调用失败 |

调用方提供有效、对齐且独占可写的输出地址及真实容量。宿主不得在一次函数调用期间并发更改同一块输出内存。桥接序列化实例与注册表访问；跨线程可调用，决定同一实例业务顺序由宿主同步。句柄 0 保留，进程内销毁后失效且不得复用。P0 每个实例含一个调试实体；每实例仅有一格下一帧输入缓冲区。

## 格式 1.0

P0 交换文档为 UTF-8 JSON，根字段 `format` 取大写 OFC、OFA、OGP、OFL，`format_version` 为字符串 `1.0`。Draft 2020-12 校验结构，运行同一工具进行本地引用校验。未知版本或未定义字段需要迁移。相对资源路径以引用文档目录为根，用正斜线分隔，禁止越出根目录。外部文档按声明的类型递归校验。

| 文档 | 冻结的根字段（另含公共字段） |
|---|---|
| OFC manifest | id, author, license, character, attributes, moves, animations, hitboxes, sounds, assets, licenses, dependencies |
| OFA | id, loop, source, frames。source.kind 取 sequence 或 sheet；frame 含 duration、origin、events 以及 image 或 index |
| OGP | id, title, characters, stages, layout, audio, fonts, theme, modes, settings, dependencies |
| OFL | id, screens。六个屏幕名为 main_menu、character_select、versus、battle_hud、pause、result |

角色 manifest 引用独立角色信息、属性、招式、判定框和 OFA 文档。OGP 引用角色 manifest 与布局；OFL 描述元素 id、type、x、y 和可选文本及资源。P0 固定的结构属于首版校验契约，新版本必须保留对应历史校验器或提供显式转换。
