# P6 任务书 V1.0 · 确定性与回放

依照[唯一项目总纲第四章、P6 和第十四章](../governance/PROJECT_CHARTER_V1.0.md)与 [ADR-009](../architecture/ADR-009.md)实施。P5 的对战场景与原生模拟器均复用现有战斗引擎。

|交付项|运行验收|
|---|---|
|固定帧与可复现随机流|指定相同种子和输入，连贯运行产生相同状态与随机流；拒绝输入后可原样重试。|
|完整快照、恢复与哈希|回到交手中的帧，继续推进并逐帧比对；覆盖投射物、动作年龄、命中状态、连击和多人。错误快照返回失败，保留当前状态。|
|记录、播放与定位|保存带完整规则的录像，其他进程独立读盘验证；受控修改输入或预期哈希，报告首个不一致帧。真实 Godot 训练记录可由同一 CLI 验证。|
|回归与表现边界|覆盖单角色移动、双角色攻击、连招、双线切换、四人战斗、同帧互殴、快照恢复和输入回放。权威比较不依赖 Godot 渲染或浮点表现。|
|集成与交付|独立 QA 检查真实开发与导出入口、四目标构建与 60 Hz 帧预算，记录恢复、回放及快照成本；汇总已知限制供负责人签收。|
