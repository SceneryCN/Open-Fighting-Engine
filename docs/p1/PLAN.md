# P1 实施与验证

起点为负责人签收的 be5939e。第十章要求独立 Rust 双人核心、可运行的模拟程序、自动化测试、接口文档与实测性能。战斗表现使用逐帧终端模拟器；Godot 仍运行已经签收的 ABI v1 技术样例。图形化战斗接入属于 P4。

|顺序|负责人|交付条件|
|---|---|---|
|冻结契约|Architecture / Tech Lead|定义一帧输入、整数坐标、攻击和切线时序、碰撞与事件|
|核心与样例|Combat Core / Simulator|两人分别提交移动、跳、切线、攻击和防御，通过同一权威模拟推进|
|集成|Tech Lead|样例使用 OFC 数据，CI 校验样例、运行模拟器与回归测试，记录 Criterion 测量|
|独立验证|QA|按实际帧检查命中、防御、击退、换线与跳跃，复核事件和失败输入，再回归 P0|
|签收|项目负责人|审阅代码、证据和已知限制，决定是否批准进入 P2|

风险主要在动作边界帧、同一招重复扣血、切线途中被命中、输入顺序偏置和极端整数参数。验收使用精确帧序列和交换双方的对照场景。后续阶段的取消链、投技、投射物和四人模式须另获授权。
