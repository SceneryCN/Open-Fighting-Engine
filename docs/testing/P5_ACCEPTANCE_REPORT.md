## QA 发现与复测

- 两份正式包起初把能量上限设为零，超必杀输入无法发动。修复后双方可实际消费能量并进入各自的超必杀。
- 从暂停恢复后，空白界面遮住训练按钮。修复后真实鼠标点击切换框显示，自动化从主菜单到对局也使用鼠标事件。
- 导出版本曾将命中音效路由到 Master，导致音效设置失效。修复后独立导出程序的实际命中声使用 SFX。修复音乐关闭流程后，两轮发布冒烟均正常退出。
- 旧单招角色收到额外招式按键时会停止推进。输入端现在依据角色的实际招式数映射按键，外部旧包兼容性复测通过。

## 图形帧时间

Compatibility 渲染器、960 × 540 视口、60 FPS 上限。从默认示范游戏加载相应模式，保持音乐播放，预热 120 个绘制帧，每轮采集 600 个相邻 frame_post_draw 之间的墙钟间隔。四人使用错开的进攻、防御与切线输入；训练样本开启原生碰撞框。物理处理时间从输入注入到该次场景物理处理结束。屏幕实际扫描输出和物理手柄硬件未单独测量。

|场景|平均 FPS|绘制 P95 / P99 / 最大 (ms)|超过 25 ms|物理处理 P99 / 最大 (ms)|
|---|---:|---:|---:|---:|
|四人混战|60.023|20.087 / 22.006 / 23.186|0|2.533 / 4.417|
|四人混战|60.004|17.578 / 18.553 / 34.232|1|0.271 / 0.276|
|训练|59.998|20.394 / 21.029 / 21.826|0|0.506 / 0.550|

三轮平均值接近 60 FPS。最慢一次绘制间隔为 34.232 ms，三个样本的绘制 P99 均超过 16.67 ms。
