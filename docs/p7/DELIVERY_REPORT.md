# P7 SDK 与 Mod 基础交付报告

作者可以从独立 Rust 项目生成 Rook，编辑生命、伤害与逐帧动画，打包为 OFC 并加入自己的 OGP 项目。游戏按项目的标题、模式、角色顺序与纵深投影运行。示例项目和引擎一起提供。[作者入门](../p7/AUTHORING.md) · [SDK API 与示例](../p7/SDK.md) · [任务书](../p7/TASK_V1.md) · [架构决议](../architecture/ADR-010.md)

## 交付内容

- 通用作者包提供两个 MIT Rust SDK、独立作者示例、可编辑的项目与角色、Schema、CLI 和许可。四个桌面运行时沿用同一个数据接口。
- CLI 支持目录与 ZIP 归档，递归校验项目中的角色、动作、动画和布局，打包时保留关联资源。可将本地目录或 OFC 归档按指定顺序追加到项目。
- 游戏载入角色时从原生对战读取初始动画图像与区域，选人菜单和实际对战使用同一份数据。项目资源中的舞台、布局与音频随包分发，本阶段游戏沿用内置表现。启动遇到重复角色 ID 或待解析的依赖会报告错误。

## 验收

独立 QA 将作者包与游戏包分别解到仓库外。两名第三方角色通过选人进入 Rust 对局，自定义攻击造成 23 点伤害，受击方的生命与血条均从 113 降至 90。六种错误输入均在启动游戏前被拒绝。85 项 Rust 测试、两项单独运行的性能与内存测试、3 项 CTest、24 项 Python 测试通过，编辑器与导出程序均通过历史场景回归。[独立 QA 报告](../testing/P7_ACCEPTANCE_REPORT.md)

在 M1 Max 的真实导出窗口预热 120 帧后采样 600 个绘制间隔，同期推进 600 个模拟帧。平均 59.983 FPS，绘制间隔 P99 为 20.986 ms，最长 23.728 ms。其他平台的 GPU 帧时间尚待实机测量。[机器记录](../testing/evidence/p7-author.json)

当前状态为 TESTING，待项目负责人签收。[P6 交付归档](../p6/DELIVERY_REPORT.md)
