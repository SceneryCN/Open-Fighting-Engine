# P7 任务书 V1.0 · SDK 与 Mod 基础

依据[项目总任务书第五章、P7 与第十四至十六章](../governance/PROJECT_CHARTER_V1.0.md)和 [ADR-010](../architecture/ADR-010.md)。

|交付项|验收路径|
|---|---|
|独立角色与动画 Rust SDK|以外部作者工程编译，生成 OFC 文档和含事件、原点、持续帧的 OFA。覆盖序列和图集两种来源。|
|角色示例与项目样例|提供可编辑的完整数据、素材与许可，可从干净目录校验、打包并加载。|
|CLI 与格式文档|说明制作、校验、检查、打包、启动项目、引入 Mod 的完整步骤。解释支持的版本、依赖及资源路径。|
|基础加载|从项目和追加 Mod 构造选人名单，按项目配置进入游戏，真实 Rust 战斗及 Godot 动画、生命显示与数据一致。错误输入有可定位的诊断。|
|交付验证|独立 QA 运行源码、导出及回归。记录平台、构建、实测性能、已知限制，交项目负责人验收。|
